# Presentacion para cliente

## Que incluye
- Catalogo publico con listado y ficha de producto
- Panel /admin para cargar, editar y borrar productos
- Subida de imagenes desde la misma pagina

## Que NO incluye
- Carrito
- Pagos

## Stack
- Next.js (App Router) + Tailwind
- Hosting: Cloudflare Workers (OpenNext)
- Datos e imagenes: Firebase (Firestore + Storage)

## Beneficios
- Operacion simple para la duenha
- Hosting rapido y escalable
- Sin servidor propio que mantener
