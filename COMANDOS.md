# Comandos utiles

## Desarrollo
```bash
npm install
npm run dev
npm run build
```

## Deploy
```bash
git add .
git commit -m "Descripción de cambios"
git push
```

El deploy a Vercel es automático al hacer push. Si no está configurado, usa:
```bash
npx vercel --prod
```
