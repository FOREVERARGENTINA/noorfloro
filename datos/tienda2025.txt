Cloudflare Pages + Firebase/Firestore: Arquitectura sugerida (Supabase references removed)
Stack final
Frontend: Cloudflare Pages (Next.js 14+)
Backend/DB: Supabase (PostgreSQL + Auth + Storage + Edge Functions)
Edge: Cloudflare Workers (webhooks, cache, rate limiting)
Pagos: Mercado Pago + Mobbex
Keep-alive: Cron-job.org (ping cada 6 días)

  ├─ /app (Next.js App Router)

Base de datos (Supabase PostgreSQL)
sql-- products
id uuid PRIMARY KEY
sku varchar UNIQUE
name varchar
description text
price decimal
stock integer
images jsonb -- ['url1', 'url2']
category varchar
created_at timestamp

-- orders
id uuid PRIMARY KEY
customer_id uuid REFERENCES customers
items jsonb -- [{product_id, qty, price}]
total decimal
status varchar -- pending/paid/shipped/delivered
payment_id varchar -- MP payment ID
shipping_address jsonb
created_at timestamp

-- customers
id uuid PRIMARY KEY (= auth.users.id)
email varchar
name varchar
phone varchar
addresses jsonb
created_at timestamp
```

**Row Level Security (RLS)**:
- Clientes ven solo sus órdenes
- Admins acceso total
- Productos públicos para todos

## Flujo completo de compra

### 1. Usuario navega catálogo
```
Cloudflare Pages → fetch productos desde Supabase
└─ Cache: Cloudflare CDN (edge cache)
```

### 2. Agrega al carrito
```
localStorage del browser
└─ No toca backend hasta checkout
```

### 3. Checkout
```
Frontend → Cloudflare Worker or Firebase Function: create-mp-preference (implement server-side logic to create Mercado Pago preference and persist orders to Firestore)
└─ Edge Function → Mercado Pago API → devuelve init_point
└─ Frontend redirect a MP checkout
```

### 4. Usuario paga en MP
```
Mercado Pago procesa pago
└─ Envía webhook a Cloudflare Worker
```

### 5. Webhook procesa pago
```
Cloudflare Worker recibe POST /webhook/mp
├─ Valida x-signature (HMAC)
├─ Consulta estado pago en MP API
├─ Actualiza order.status = 'paid' en Supabase
├─ Trigger Supabase → Edge Function: send-order-email
└─ Edge Function: update-inventory (resta stock)
```

### 6. Confirmación
```
Supabase Edge Function → Resend API → email al cliente
Frontend polling → actualiza UI con orden confirmada

Cloudflare Workers (Edge Functions)
Worker 1: Webhook Mercado Pago
typescript// worker-webhook-mp.ts
export default {
  async fetch(request) {
    // Validar x-signature
    const isValid = validateMPWebhook(request)
    if (!isValid) return new Response('Invalid', { status: 401 })
    
    // Consultar pago en MP
    const payment = await fetchMPPayment(paymentId)
    
    // Actualizar en Supabase
    await supabase.from('orders')
      .update({ status: payment.status })
      .eq('payment_id', paymentId)
    
    return new Response('OK')
  }
}

Integración Mercado Pago
En Supabase Edge Function:
typescript// /supabase/functions/create-mp-preference/index.ts
import { MercadoPagoConfig, Preference } from 'mercadopago'

const client = new MercadoPagoConfig({ 
  accessToken: Deno.env.get('MP_ACCESS_TOKEN') 
})

const preference = new Preference(client)
const response = await preference.create({
  items: [{
    title: 'Orden #123',
    quantity: 1,
    unit_price: 15000
  }],
  back_urls: {
    success: 'https://tutienda.com/success',
    failure: 'https://tutienda.com/failure'
  },
  notification_url: 'https://webhook.tudominio.workers.dev/mp'
})

return new Response(JSON.stringify(response))

Keep-alive automático

    await fetch('https://tuproyecto.supabase.co/rest/v1/products?limit=1', {
      headers: { apikey: env.SUPABASE_ANON_KEY }
    })

Costos reales
Mes 1-6 (gratis):

Cloudflare: $0
Supabase: $0
Cron-job: $0
Resend: $0 (3K emails/mes)
Total: $0/mes

Escalabilidad:

5GB bandwidth Supabase = ~2,500 visitas/mes
500MB DB = ~50K productos pequeños
Al superar → Supabase Pro $25/mes

Breaking point: ~1,000 órdenes/mes o 5K visitas/mes

Ventajas sobre Render + Neon
✅ Bandwidth ilimitado en Cloudflare
✅ Auth OAuth integrado (Google, Facebook)
✅ Real-time subscriptions (stock updates live)
✅ Storage integrado (no necesitás Cloudinary)
✅ Edge Functions más cerca de usuarios
✅ Dashboard Supabase superior a CLI Neon
Único trade-off: Necesitás cron job (5 min setup)
