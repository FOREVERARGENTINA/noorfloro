# EMPIEZA AQUI

## Inicio rapido
```bash
npm install
npm run dev
```
Abrir: http://localhost:3000

## Paginas principales
- / (inicio)
- /productos
- /producto/[id]
- /admin/login
- /admin
- /admin/productos

Nota: este proyecto es catalogo + admin. No hay carrito ni pagos.

## Deploy
- `COMO_DEPLOYAR.md` (deploy automático con git push)
- `DEPLOYMENT.md` (setup Firebase + variables)
